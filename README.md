# CamFlux
Multiple cameras. Independent streams. One control panel.

A lightweight Windows desktop application for independent camera streams over SRT, powered by FFmpeg. Designed for remote live production with MediaMTX and OBS.

Status: pre-alpha; implementation pending.

See [MVP](docs/MVP.md), [architecture](docs/ARCHITECTURE.md), [roadmap](docs/ROADMAP.md) and [MediaMTX setup](docs/MEDIAMTX.md).
