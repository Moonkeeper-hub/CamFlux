# Roadmap
- v0.1: basic GUI, FFmpeg setup, device enumeration, x264 SRT, profiles, process supervision, read links.
- v0.2: hardware encoder probes (NVENC, AMF, QSV), presets, robust recovery.
- v0.3: preview without competing capture, local recording with independent network failure handling.
- v0.4: diagnostics, measured stream metrics, bandwidth estimates.
- v0.5: MediaMTX configuration and OBS scene export.
- v0.6: audio routing and synchronization.
- v1.0: validated release, installer, documentation.
Hardware and network capacity must be measured on real equipment.
